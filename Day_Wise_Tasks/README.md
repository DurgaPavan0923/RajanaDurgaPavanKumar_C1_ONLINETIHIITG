## Programmatic Architecture & Overview

This directory contains the complete day-wise, task-wise lifecycle artifacts for the 28-day AI/ML Internship curriculum. All 56 individual tasks (2 tasks per day across 28 days) are structured in dedicated folders (`Day_X_Task_Y`), each containing:
1. `dayX_<topic>.ipynb` - Interactive Jupyter notebook conforming strictly to the 20-cell reference standard, with full outputs saved in-notebook.
2. `dayX_<topic>.py` - 1-to-1 Python script mirror with matching step order, section headers (`# %% [markdown]`), logic, and saved output artifacts.
3. `outputs/figures/` - High-resolution diagnostic charts and visual evaluations (`.png`, dpi=150, bbox_inches="tight").
4. `outputs/tables/` - Serialized performance metrics, data catalogs, and validation scorecards (`.csv`).
5. `README.md` - Per-task technical specification, operational scope, methodology, run instructions, and embedded artifact links.
